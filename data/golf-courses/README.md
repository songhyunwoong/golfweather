# 골프장 DB

## 현재 상태: v0 (OpenStreetMap 기반 초안)

| 항목 | 값 |
|---|---|
| 골프장 수 | 473곳 (운영 중 골프장은 약 527곳이므로 약 90%) |
| 이름 있는 곳 | 417곳 |
| 검수 표시 없는 곳 | 372곳 |
| 원천 | OpenStreetMap `leisure=golf_course` 영역 (2026-11-11 기준) |

각 골프장에는 코스 영역 중심 좌표, 면적, 대표 고도(영역 안 9개 지점의 중앙값), 시도·시군구, 기상청 단기예보 격자(nx, ny), 정규화 이름과 초성이 들어 있다.

## 파일

| 파일 | 내용 |
|---|---|
| `courses.json` | 앱·검색용 데이터 |
| `courses.csv` | 검수용 표 (엑셀에서 바로 열림) |
| `build_from_osm.py` | 빌드 스크립트 |
| `hangul.py` | 이름 정규화, 초성 추출, 기상청 격자 변환 |
| `raw/osm_golf_course_kr.json` | OSM 원본 (Overpass `out tags geom`) |

## 만드는 방법

1. OSM에서 한국의 `leisure=golf_course`를 도형과 함께 받는다.
2. 면적 10 ha 미만과 이름에 연습장·스크린·파크골프가 들어간 것을 뺀다.
3. 250 m 안에 있고 이름이 같은 계열이거나 이름이 없는 영역을 한 골프장으로 묶는다.
4. 중심점, 면적, 고도(Copernicus GLO-90, Open-Meteo 고도 API), 행정구역, 기상청 격자를 계산한다.

다시 빌드하려면 행정동 경계 파일(34 MB, 저장소에 넣지 않음)을 `raw/`에 받아야 한다.

```bash
git clone --depth 1 https://github.com/vuski/admdongkor.git /tmp/adm && cp /tmp/adm/ver20261001/HangJeongDong_ver20261001.geojson raw/
```

```bash
pip install shapely pyproj && python3 build_from_osm.py
```

## 알려진 문제

- 이름으로 찾으면 안 나오는 유명 골프장이 있다(예: 안양CC, 핀크스GC, 오크밸리CC, 88CC). OSM에 영역은 있지만 이름이 없거나, 영역 자체가 없는 경우다.
- OSM 이름 표기가 제각각이다(`베어크리크G.C`, `남서울cc`). 공식 명칭은 인허가 데이터에서 가져와야 한다.
- 회원제/비회원제 구분, 홀 수, 영업 상태는 아직 없다.

## 다음 단계: 인허가 데이터 결합 (v1)

행정안전부 **등록체육시설업 조회서비스**(공공데이터포털 15155018, 골프장·스키장·자동차경주장 포함)와 결합한다.

- 좌표계는 EPSG:5174이므로 WGS84로 변환한 뒤, OSM 영역 안에 있거나 1 km 안에 있는 인허가 지점을 연결한다.
- 인허가 데이터에서 공식 명칭, 영업 상태, 주소를 가져오고, OSM에서 영역·중심점·고도를 가져온다.
- 연결되지 않은 인허가 골프장은 주소 좌표로 추가하고 "영역없음"으로 표시한다.
- API 키는 환경 변수 `DATA_GO_KR_SERVICE_KEY`로 읽는다.
