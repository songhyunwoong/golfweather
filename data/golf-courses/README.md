# 골프장 DB

## 현재 상태: v1 (인허가 데이터 + OpenStreetMap 결합)

| 항목 | 값 |
|---|---|
| 골프장 수 | 520곳 |
| 인허가 기록과 연결된 곳 | 425곳 |
| 코스 영역까지 있는 곳 | 473곳 (나머지 47곳은 인허가 주소 좌표만 있음) |
| 검수 표시 없는 곳 | 287곳 |
| 위치를 정하지 못한 인허가 기록 | 48건 (`unresolved_licences.csv`) |
| 기준일 | 2026-11-11 |

인허가 기록은 영업·휴업 625건이며, 한 골프장이 회원제·대중제로 나뉘어 여러 건인 경우가 많다. 577건을 골프장에 배치했다.

각 골프장에는 이름, 별칭, 회원제 구분, 주소, 좌표, 면적, 대표 고도, 시도·시군구, 기상청 단기예보 격자(nx, ny), 초성이 들어 있다.

## 원천별 역할

| 원천 | 가져오는 것 |
|---|---|
| 행정안전부 생활_골프장 조회서비스 (공공데이터포털 15154978) | 공식 명칭, 영업 상태, 회원제 구분, 주소, 전화 |
| OpenStreetMap `leisure=golf_course` | 코스 영역, 중심점, 면적, 고도 계산 지점 |
| Copernicus GLO-90 (Open-Meteo 고도 API) | 고도 (영역 안 9개 지점의 중앙값) |
| 행정동 경계 (vuski/admdongkor) | 시도·시군구 |

## 파일

| 파일 | 내용 |
|---|---|
| `courses.json` | 앱·검색용 데이터 |

| `hangul.py` | 이름 정규화, 초성 추출, 기상청 격자 변환 |
| `raw/` | 원본 (인허가 JSON, OSM JSON) |

## 다시 만들기

행정동 경계 파일(34 MB, 저장소에 넣지 않음)을 `raw/`에 받는다.

```bash
git clone --depth 1 https://github.com/vuski/admdongkor.git /tmp/adm && cp /tmp/adm/ver20261001/HangJeongDong_ver20261001.geojson raw/
```

```bash
pip install shapely pyproj && python3 fetch_licence.py && python3 build.py
```

OSM 원본은 Overpass에서 아래 질의로 받는다.

```
[out:json][timeout:300];area["ISO3166-1"="KR"][admin_level=2]->.a;(nwr["leisure"="golf_course"](area.a););out tags geom;
```

## 결합 규칙

1. OSM 영역 중 10 ha 미만과 연습장·스크린·파크골프를 뺀다. 250 m 안의 같은 계열 영역은 한 골프장으로 묶는다.
2. 인허가 좌표(EPSG:5174)를 변환해, 800 m 안에 있는 코스 영역에 연결한다. 후보가 여럿이면 이름이 맞는 쪽을 고른다.
3. 좌표가 없거나 못 찾은 기록은 같은 시군구 안에서 이름으로 연결한다.
4. 그래도 남은 기록 중 좌표가 있는 것은 그 좌표에 새 골프장으로 넣는다("영역없음").
5. 이름은 인허가 명칭을 우선한다. 인허가 명칭이 운영 법인명으로 보이면(예: 남서울CC의 "경원건설") OSM 이름을 쓴다.

| 표시 | 건수 | 뜻 |
|---|---|---|
| 인허가미확인 | 95 | OSM에는 있으나 연결된 인허가 기록이 없음. 군 체력단련장, 이름 없는 영역, 위치를 못 정한 48건의 짝일 수 있음 |

| 이름불일치 | 43 | 인허가 명칭과 OSM 이름이 다름. 개명했거나 좌표가 옆 골프장에 붙었을 수 있음 |
| 이름없음 | 32 | 이름을 정하지 못함 |
| 병합확인 | 19 | 이름이 다른 인허가 기록이 한 곳에 묶임 |
| 동명 | 2 | 정규화한 이름이 같은 곳이 둘 |

## 알려진 문제

- 회원제 구분이 있는 곳은 178곳뿐이다. 인허가 원본의 세부업종이 절반가량 비어 있다.
- 홀 수는 원본에 없다.
- 위치를 못 정한 48건은 좌표가 없고 이름으로도 못 찾은 기록이다. 주소가 있으므로 주소 좌표 변환(지오코딩)으로 풀 수 있다.
- "인허가미확인"과 "영역없음"·미배치 기록 중 일부는 같은 골프장이다. 클럽하우스 주소가 코스 영역에서 800 m 넘게 떨어졌거나 이름 표기가 크게 다른 경우다.
