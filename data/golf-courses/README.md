# 골프장 DB

## 현재 상태: v2 (인허가 데이터 + OpenStreetMap + 수동 검수)

| 항목 | 값 |
|---|---|
| 골프장 수 | 495곳 (전부 검수 완료) |
| 코스 영역 중심 좌표 | 436곳 |
| 인허가 주소 좌표 | 44곳 |
| 검수에서 넣은 좌표 | 15곳 |
| 위치를 정하지 못한 인허가 기록 | 0건 |
| 기준일 | 2026-11-12 |

검수 결과(`overrides.json`)는 빌드할 때마다 다시 적용된다.

| 검수 판정 | 건수 |
|---|---|
| 확인 완료 | 480곳 (이름 수정 5곳 포함) |
| 삭제 (골프장 아님) | 40곳 |
| 위치 없던 인허가 → 새 골프장으로 추가 | 15건 |
| 위치 없던 인허가 → 기존 골프장에 연결 | 17건 (검수자가 연결 2건, 넣은 좌표가 기존 골프장 1.5 km 안이라 자동 연결 15건) |
| 위치 없던 인허가 → 제외 | 16건 |

## 원천별 역할

| 원천 | 가져오는 것 |
|---|---|
| 행정안전부 생활_골프장 조회서비스 (공공데이터포털 15154978) | 공식 명칭, 영업 상태, 회원제 구분, 주소, 전화 |
| OpenStreetMap `leisure=golf_course` | 코스 영역, 중심점, 면적, 고도 계산 지점 |
| Copernicus GLO-90 (Open-Meteo 고도 API) | 고도 (영역 안 9개 지점의 중앙값) |
| 행정동 경계 (vuski/admdongkor) | 시도·시군구 |

## 다시 만들기

행정동 경계 파일(34 MB, 저장소에 넣지 않음)을 `raw/`에 받는다.

```bash
git clone --depth 1 https://github.com/vuski/admdongkor.git /tmp/adm && cp /tmp/adm/ver20261001/HangJeongDong_ver20261001.geojson raw/
```

```bash
pip install shapely pyproj && python3 fetch_licence.py && python3 build.py
```

OSM 원본은 Overpass에서 아래 질의로 받는다.

```
[out:json][timeout:300];area["ISO3166-1"="KR"][admin_level=2]->.a;(nwr["leisure"="golf_course"](area.a););out tags geom;
```

## 결합 규칙

1. OSM 영역 중 10 ha 미만과 연습장·스크린·파크골프를 뺀다. 250 m 안의 같은 계열 영역은 한 골프장으로 묶는다.
2. 인허가 좌표(EPSG:5174)를 변환해, 800 m 안에 있는 코스 영역에 연결한다. 후보가 여럿이면 이름이 맞는 쪽을 고른다.
3. 좌표가 없거나 못 찾은 기록은 같은 시군구 안에서 이름으로 연결한다.
4. 그래도 남은 기록 중 좌표가 있는 것은 그 좌표에 새 골프장으로 넣는다("영역없음").
5. 이름은 인허가 명칭을 우선한다. 인허가 명칭이 운영 법인명으로 보이면(예: 남서울CC의 "경원건설") OSM 이름을 쓴다.

## 검수 표시 (`review` 열)

검수를 마친 골프장은 표시가 지워진다.

| 표시 | 건수 | 뜻 |
|---|---|---|
| 좌표확인 | 0 | 검수 좌표와 주소의 시군구가 다름. 이 표시가 있으면 예보 대상에서 빠진다 |
| 동명 | 2 | 정규화한 이름이 같음 (용평리조트 골프클럽 두 곳) |

## 알려진 문제

- 회원제 구분이 있는 곳은 185곳뿐이다. 인허가 원본의 세부업종이 절반가량 비어 있다.
- 홀 수는 원본에 없다.
- 이름 표기가 원본 그대로라 제각각이다(`남서울cc`, `베어크리크골프클럽`).
- 인허가 주소 좌표만 있는 44곳과 검수 좌표 15곳은 고도가 한 점의 값이다.
- 정남진골프리조트는 좌표를 고친 뒤 이미 목록에 있던 JNJ골프리조트(같은 골프장의 현재 이름)에 연결됐다. 아크로컨트리클럽은 고친 좌표로 추가됐다.
- 오시아노골프클럽은 파인비치골프링크스 안의 코스라 파인비치에 연결했다. "오시아노"로 검색하면 파인비치가 나온다.
- 검수에서 좌표가 같게 들어간 인허가 기록은 한 골프장으로 묶였다(예: 벨라스톤 컨트리클럽과 벨라45 마스터스).
