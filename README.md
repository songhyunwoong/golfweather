# golfweather — 골프장 날씨 앱 (가칭: 티업웨더)

국내 골프장을 선택하면 7일(최대 15일)의 강수·기온·바람을 모델별로 보여주고, 각 모델의 **실측 기반 신뢰도**를 함께 표시하는 앱 프로젝트입니다.

## 문서

- [개발 계획서](docs/PLAN.md) — 요구사항, 데이터 소스, 기능 설계, 아키텍처, 데이터 모델, API, 로드맵, 비용, 법률, 리스크
- [개발 계획서 웹 페이지](docs/plan.html) — 계획서의 웹 버전 원본 (인터랙티브 그래프·초성 검색 데모 포함, [게시본](https://claude.ai/artifact/4Ak3rrZ1MqnqsZkfsBuuLN))
- [날씨 모델 검증](research/model-verification/) — 12개 수치모델을 기상청 관측과 대조한 재현 가능한 분석 (2026-08~11)

## 검증 한 줄 요약

- **1~3일**: DWD ICON이 단일 모델 중 가장 좋습니다.
  - 강수 적중 1위, 비 과다 예보가 가장 적고, 바람 오차도 가장 작습니다.
- **4~7일**: ECMWF AIFS와 IFS, 그리고 여러 모델 평균(블렌드)이 앞섭니다.
- **8일 이후**: ECMWF AIFS가 가장 낫지만, 강수는 참고 수준입니다.
