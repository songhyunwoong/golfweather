# 블렌드 가중치 실험

예보 기간(며칠 뒤)과 항목(기온·바람·비)별로 모델 가중치를 다르게 주면 지금의 단순 평균·중앙값 블렌드보다 나아지는지 확인한다.

## 자료

| 경로 | 기간 | 상태 |
|---|---|---|
| 공개 실행 자료(`s3://openmeteo/data_run`, 키 불필요) | 2026-08-10 이후, 1~15일 뒤 | 사용 |
| Open-Meteo 과거 실행 API(1년, 11개 모델) | 2025-11 이후, 1~7일 뒤 | 유료 Professional 요금제 이상에서만 열려 보류 |

## 실행

```bash
cd pipeline && python3 verify.py --start 2026-08-10 --end 2026-11-10 --no-write --dump /tmp/dump
```

```bash
cd research/blend-weights && python3 pairs_dump.py /tmp/dump
```

```bash
python3 experiment.py
```

| 파일 | 내용 |
|---|---|
| `pairs_dump.py` | `verify.py --dump`가 실행별로 남긴 예보·관측을 `pairs_runs.npz`로 묶는다 |
| `experiment.py` | 직전 `TRAIN_DAYS`일로 가중치·치우침을 정해 다음 `TEST_DAYS`일을 채점하는 굴림 평가. 결과는 `results/` |
| `fetch_prev.py`, `pairs_prev.py`, `stations_obs.json` | 과거 실행 API용(보류). 요금제가 맞으면 그대로 1년 실험에 쓸 수 있다 |

## 결과 (2026-08-10 ~ 11-10 실행, 채점 구간 9월 중순 ~ 11월, 관측 지점 32곳)

직전 30일로 가중치·치우침을 정하고 다음 7일을 채점했다(12개 구간 합산). 숫자는 `results/`에 있다.

| 항목 | 지금 방식 | 가장 나은 실용안 | 1일 | 3일 | 5일 | 7일 | 판단 |
|---|---|---|---|---|---|---|---|
| 풍속 평균 오차(m/s) | 4모델 평균 | 모델·기간별 치우침 보정 + 성적 가중(5모델) | 1.07 → 0.94 | 1.09 → 0.96 | 1.08 → 0.98 | 1.15 → 1.05 | 채택 후보. 9·10·11월 모두 개선 |
| 기온 평균 오차(°C) | 4모델 평균 | 같은 방식 | 1.08 → 1.06 | 1.21 → 1.19 | 1.33 → 1.32 | 1.57 → 1.53 | 차이 작음(1~3%) |
| 비 유무 적중(ETS) | 4모델 중앙값, 1 mm 이상 | 같은 중앙값, 기준만 조정(약 2~2.5 mm) | 0.61 → 0.66 | 0.54 → 0.58 | 0.38 → 0.40 | 0.27 → 0.22 | 보류. 9·10월은 개선, 11월은 악화 |

- **기간별 가중치**: 학습된 가중치는 기대한 방향으로 움직인다. 기온 기준 ICON 0.25(1일) → 0.17(7일), AIFS 0.25 → 0.32(5일). 다만 가중치만으로 얻는 점수 차이는 작다.
- **바람**: 개선의 대부분은 가중치가 아니라 치우침 보정에서 나온다. 관측 대비 평균 과대 예보가 ICON +0.16, ECMWF +0.67, AIFS +0.78, UKMO +0.78, GFS +0.96 m/s다.
- **비**: 가중 평균·가중 다수결은 지금의 중앙값보다 낫지 않다. 모델들이 약한 비를 너무 자주 예보한다(빈도 1.2~1.5배).
- **8일 이후 기온**: GFS를 더해 5모델로 하면 4~6% 나아진다(ICON·UKMO가 빠지는 구간).
- **한계**: 석 달(늦여름~가을)뿐이다. 관측소 바람과 골프장 바람은 노출 조건이 다를 수 있다.
